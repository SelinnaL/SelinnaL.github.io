Security Analysis of the audiowmark Scheme

A cryptographic security analysis of audiowmark, an open-source audio watermarking tool. We found structural weaknesses, demonstrated four practical attacks, and proposed three defenses.

Applied Cryptography Python Signal Processing

Paper (PDF)

Overview

Audio watermarking hides inaudible, machine-readable data in audio so ownership can be proven later, even after copying or compression. audiowmark is a widely referenced open-source tool that embeds a 128-bit payload using a private AES-based key, claiming the watermark is inaudible, survives lossy compression, and stays secure without the key.

For our 6.5610 (Applied Cryptography) final project, our team treated audiowmark as a cryptographic system and asked whether those security claims hold against an adversary. We found three structural weaknesses, demonstrated four practical attacks (overlay, override, forgery, and removal) in which none of them require the victim's key, and proposed defenses.
